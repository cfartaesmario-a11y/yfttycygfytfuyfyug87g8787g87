Conecta la base de datos

1. Entra en console.firebase.google.com y crea un proyecto.
2. Compilación → Realtime Database → Crear base de datos → modo de prueba.
3. Rueda dentada → Configuración del proyecto → Tus apps → icono </>.
4. Copia el bloque firebaseConfig que te enseña y pégalo aquí abajo.
